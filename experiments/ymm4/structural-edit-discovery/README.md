# Structural edit discovery

Discover the YMM4 4.55.1.1 host surfaces used by standard layer insertion/deletion/reordering before building the no-Harmony folder-range tracking probe.

This probe does not mutate layer structure. It enumerates relevant CommandType entries, command objects, Timeline / TimelineViewModel / MainViewModel / LayerSettings / LayerSelection methods and properties, layer-related host types, and UndoRedoManager events/methods.
