# Real-audio loop ranking benchmark 001

## Goal

Run the current lightweight loop-analysis stack against **real rendered seamless music loops**, using pinned upstream ZIP identities and stem-remixed / phase-rotated target variants.

This is the first benchmark in the lab where the harmonic/rhythmic material is not generated by our synthetic fixture code.

## Ground Truth construction

Published tempo and the exact WAV lengths correspond to integer loop beat counts:

- Arcade, Vellum, Anvil, Rust, Timber: 16 beats / 4 bars;
- Prism: 8 beats / 2 bars.

The benchmark uses the source pack's `wav/loop.wav` as the reference take. Target takes are rebuilt from the separate stems with deterministic, non-uniform stem gains, then circularly rotated by exact integer bar frame counts.

This preserves the source pack's sample-exact loop phase while changing the mix enough that exact PCM identity cannot solve the task.

For each pack:

- target A: one-bar rotation + stem-balance profile A;
- target B: two-bar rotation where the loop has 4 bars, otherwise one-bar rotation + profile B.

Total: 12 real-audio ranking queries.

## Analyzer under test

```text
real source / remixed target
  -> Beat This small0
  -> detected downbeat candidates
  -> chroma-context score
  -> adaptive 2 -> 4 -> 8 bar context by Top1-Top2 margin >= 0.05
  -> hidden Ground Truth scoring
```

Ground Truth is not used to choose candidates, scores or context length.

## Diagnostic treatment of failures

This experiment is intentionally allowed to expose a weakness. In particular, `Prism — Void Loop` is published as a pulse-free loop, so a rhythm-grid-first architecture may abstain or fail there.

The workflow therefore distinguishes:

- **pipeline execution PASS** — all six pinned packs were acquired and evaluated or explicitly abstained with a reason;
- **quality metrics** — coverage / Hit@1 / selected context, reported per pack and in aggregate.

A green run does **not** silently mean the detector solved every track.

## PASS boundary

PASS proves:

1. all six pinned ZIP digests match;
2. each source exposes the expected `loop.wav` and stems;
3. two deterministic target variants are generated per source;
4. Beat This / candidate ranking executes or returns an explicit structured abstention per query;
5. quality metrics are emitted for the covered queries;
6. third-party audio bytes are not committed or uploaded as workflow artifacts.

## NOT PROVEN

This does not yet prove arbitrary-song loop extraction, vocals, changing tempo/meter, long-form section understanding, or YMM4 integration. Quality thresholds should be set only after seeing this real-audio baseline rather than choosing a favorable target in advance.
